# 三领域实验协议（待独立角色与人工基准验收）

汽车为首个领域；其他两个领域仍待用户最终确认，推荐政务政策和企业制度。不要用三个汽车子主题替代三领域。

第二窗口从“我要开始创建知识库”开始，仅使用公开文档和 MCP，独立产生领域包及确认记录。第三窗口不读源码和候选，固定发布版完成问题。当前真实 MCP 烟测使用合成企业制度文本，不能冒充上述独立验收。

先为汽车选择约 12 份可核验样本，覆盖多系统、表格、扫描件、版本与来源差异；身份、工况、参考设计与量产适用性分开。186 PDF 文件指纹审计通过，只证明文件完整性。OCR、表格质量和业务适用性必须另行验收。

人工冻结约 40 道汽车题（至少 8 道必须组合关系与条件），其他领域各约 20 道。按资料划分开发与留出集。每题包含 id、question、expected_answer、expected_evidence_ids（可选）、provenance（人工核验依据）、题型、应拒答条件。不得由同一回答模型独自建立和裁决金标准。

开发者 evaluate 工具提交异步评测，mode=baseline 使用原文全文/向量召回，mode=semantic 允许语义记录与图；模型、轮次和 Token 预算相同。返回逐题答案、证据、轨迹、耗时、Token 及 human_grade=null，需人工评分，不自动宣称正确。

比较前检查 release manifest 的 baseline_block_ids/来源范围是否涵盖相同输入资料；当前原文基线包含已选语义记录所引用解析版本的全部块，完全未产生候选的输入资料需要单独补齐范围后才能做严格全资料比较。此限制不得隐瞒。

报告正确性、证据支持性、条件保留、无依据结论、拒答、延迟、Token、按固定价格版本计算的费用，另报构建成本。权限/固定引用检查必须全部通过。其他质量阈值由人工基准初审后与用户冻结，不能看完结果再降低门槛。

本版本尚未给出“通用性成立”的结论；真实汽车、另外两域、独立窗口及人工质量门槛均未验收。
